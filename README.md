# LUMI — My AI Study Companion

LUMI is my personal project to explore how AI can make learning easier, clearer, and more enjoyable.

## My Goals
- Understand difficult topics in simple language.
- Create short study notes and summaries.
- Practise with quizzes and questions.
- Organise revision for my college subjects.

## Current Status
I'm a beginner learning how to build apps. LUMI is currently in the planning stage.

## Future Vision
I hope to turn LUMI into a useful AI-powered study app for students.
